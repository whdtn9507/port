PORTFOLIO CASE STUDY · 2026

동물 보호 정보를
이해하기 쉬운 흐름으로 재구성하다.

프로젝트 개요

기존의 동물·반려동물·자격증 정보를 하나의 흐름으로 연결한 교육형 웹사이트 리뉴얼입니다. 사용자가 보호의 의미를 이해한 뒤 실천과 진로 정보까지 탐색하도록 구조를 정리했습니다.

개선한 경험

전체 화면 스크롤 중심 구조를 일반 스크롤 구조로 변경해 모바일 접근성을 높이고, 이미지 카드에 제목·설명·행동 버튼을 추가했습니다. 팝업은 키보드로 닫을 수 있는 dialog로 교체했습니다.

나의 역할

정보 구조 재정리, 화면 디자인, HTML·CSS·JavaScript 퍼블리싱을 담당했습니다. 기존 이미지 자산을 활용하면서 브랜드 톤과 반응형 화면을 일관되게 구성했습니다.

주요 포인트

보호 이유 → 실천 방식 → 관련 진로라는 탐색 흐름을 만들고, 사용자가 필요한 깊이의 정보만 선택해 볼 수 있게 카드와 모달 인터랙션을 적용했습니다.
