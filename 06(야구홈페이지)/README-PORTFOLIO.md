# 불꽃파이터즈 팬 페이지

기존 야구 개인 작업을 파이터즈 기준으로 전체 재구성한 포트폴리오 검토용 수정본입니다. 현재 공개 사이트에는 아직 적용하지 않았습니다.

## 이미지 교체 (Framer)
Works CMS의 불꽃파이터즈 항목에서 다음 이미지 필드를 변경합니다.

- 불꽃파이터즈 · 로고
- 불꽃파이터즈 · 메인 사진
- 불꽃파이터즈 · 단체 사진
- 불꽃파이터즈 · 선수단 이미지
- 불꽃파이터즈 · 갤러리 1 / 2 / 3
- 불꽃파이터즈 · 추가 이미지 출처

갤러리 2·3은 입력 전에는 빈 영역과 비활성 확대 버튼으로 표시하며, 사진이 입력되면 확대 버튼이 활성화됩니다. 포트폴리오 카드 대표 사진은 기존 previewImage 필드에서 별도로 변경합니다. 이미지 입력 후 상세 페이지 ▶ 미리보기에서 확인합니다.

## HTML 소스에서 교체
`data-image-slot` 속성이 있는 img의 src를 변경할 수 있습니다. 빈 사진에는 src를 추가하고 hidden을 제거하며, 해당 galleryOpen의 disabled를 제거하고 placeholder를 숨깁니다. 출처·연도·설명도 실제 사진에 맞게 수정합니다.

보도 사진은 원권리자의 자료이며 자유 이용 허락을 확인한 자료는 아닙니다. 포트폴리오 공개 전에는 사용 가능한 사진으로 교체하거나 필요한 사용 조건을 확인합니다. 공식 사이트를 사칭하지 않는 개인 팬 프로젝트입니다.

## 검증
홈·선수단을 360/390/768/1024/1440px에서 검사했습니다. 메뉴 Escape, 자연스러운 휠 이동, 갤러리 이동, 사진 확대와 포커스 복귀, 키보드 포지션 필터, 이름 검색과 빈 결과를 검사했습니다. 로컬 검사에서는 외부 사진을 대체 이미지로 처리했고 실제 사진 표시는 Framer에서 별도로 확인했습니다.
