# 불꽃파이터즈 · 이미지 없는 구성 설계

LG트윈스 공식 홈페이지(https://lgtwins.com/main)의 팀·경기·팬 서비스 정보 구조를 참고해 전면 재설계한 비공식 팬 프로젝트입니다. 기존 공개 사이트에는 아직 적용하지 않았습니다.

## 페이지
- index.html: 메인 비주얼 자리, 다음 경기, 팀 기록, 소식 탭, 선수단 카드, 팬 안내, 미디어
- team.html: 코칭스태프·선수단 프로필 배치
- game.html: 월별 달력, 목록 전환, 결과 영역
- news.html: NEWS / NOTICE / EVENT
- fan.html: 응원·티켓·경기장·스토어·미디어·공식 채널 안내
- subtask.html: 이전 선수단 URL 호환

이미지·로고·실제 경기 날짜·점수·승률·선수 명단은 이번 단계에서 제외했습니다. 회색 박스는 자리표시자이며 실제 정보와 혼동하지 않도록 등록 예정으로 표시했습니다. 티켓·상품을 직접 판매하거나 회원 정보를 수집하지 않습니다.

Framer의 FightersPreview.tsx에는 동일한 HTML/CSS/JS 문서를 넣은 검토용 화면이 연결되어 있습니다. 기존 이미지 CMS 필드는 비워두었으며 실제 이미지 연결은 다음 단계에 진행합니다.

검증: 5페이지 × 320/360/390/768/1024/1440px 30개 배치 검사 통과. 이미지 요소 0개 확인. 내부 링크, 휠 스크롤, 모바일 메뉴, 키보드 소식 탭, 달력 월 이동, 달력/목록 전환 검사 통과. Framer 구성 화면 렌더링 확인. Framer 안에서 직접 클릭하는 통합 검수는 별도 확인이 필요합니다.
